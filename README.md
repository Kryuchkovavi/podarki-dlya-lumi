# Подарки для Луми


## Структура проекта

- `index.html` — страница игры и Canvas.
- `js/main.js` — точка входа, загружает игровой контроллер.
- `js/Game.js` — игровой цикл, состояние игры, уровни, отрисовка и интерфейс.
- `js/Player.js` — базовая модель движения персонажа.
- `js/Platform.js` — модель платформы.
- `js/Collision.js` — вспомогательные проверки столкновений.
- `js/InputHandler.js` — вспомогательный обработчик клавиатуры.
- `js/Renderer.js` — вспомогательная обёртка Canvas 2D.
- `css/style.css` — оформление меню и игрового интерфейса.
- `assets/images/`, `assets/sounds/` — каталоги ресурсов; игровые тайлы лежат в `assets/tiles/`.

Основной действующий игровой контроллер исторически хранит большую часть механик в `js/Game.js`; вспомогательные классы вынесены в отдельные файлы как читаемые строительные блоки. В проекте нет сборщика и внешних библиотек: откройте `index.html` после распаковки архива.


Небольшой платформер на HTML5 Canvas и чистом JavaScript. Чип путешествует по пяти локациям, собирает подарки для Луми и старается добраться до выхода, не попадая в ямы и не сталкиваясь со слизнями.


## Игровые механики

- Пять глав с отдельной цветовой атмосферой, платформами, препятствиями и предметами для сбора.
- Физика движения: скорость, гравитация, прыжки, двойной прыжок и приземление на платформы.
- Обработка столкновений персонажа с платформами, опасными участками, слизнями, коллекционными предметами и сердечком.
- Счётчик подарков, индикатор прогресса по уровню, таймер на две минуты и три единицы здоровья.
- Чтобы открыть выход, нужно собрать все подарки уровня.
- При потере здоровья на уровне можно подобрать дополнительное сердечко.
- Пауза, повтор уровня после поражения, экран победы, выбор доступных глав и автоматическое сохранение прогресса через `localStorage`.
- Звуковые эффекты и мелодия синтезируются с помощью Web Audio API. Звук можно отключить; браузер может разрешить аудио только после нажатия пользователем на кнопку.

## Технологии и структура

- `index.html` — интерфейс, Canvas и элементы меню.
- `css/style.css` — стили оболочки, HUD, меню и карточки задания.
- `js/Game.js` — игровой цикл, физика, коллизии, уровни, ввод, отрисовка, звук и сохранения.
- `assets/` — тайлы и сведения о лицензии.

Основная логика реализована на Vanilla JavaScript, отрисовка игрового мира выполняется через Canvas 2D. Внешние игровые движки не используются. Игровой цикл использует `requestAnimationFrame`; изменение физики и таймера учитывает длительность кадра. При скрытии вкладки игра ставится на паузу. Интервал автосохранения очищается и создаётся заново при старте уровня, чтобы не накапливать интервалы.


## Применение AI-помощника и проверка

**Содержательная задача:** ревью игрового цикла, управления и коллизий, а также проверка согласованности подсказок интерфейса с реальными действиями.

**Существенный запрос к AI-помощнику:** «Проверь браузерный платформер на чистом JavaScript и Canvas. Найди несоответствия между управлением, интерфейсом и README; проверь игровой цикл, обработку прыжка, столкновения с платформами и опасностями, сбор предметов, завершение уровня и сохранение. Предлагай небольшие проверяемые изменения, не переписывая весь проект».

**Принятое предложение:** удалить неиспользуемую атаку и связанные подсказки, потому что атака не является частью выбранного игрового замысла; оставить слизней движущимися препятствиями. Уточнить README, управление и клавиатурные подсказки. Сбросить интервал автосохранения при запуске уровня, чтобы повторные старты не создавали дополнительные интервалы.

**Отклонённое предложение:** не добавлять внешнюю физическую библиотеку или игровой движок. Для небольшого учебного проекта собственная логика на Canvas и Vanilla JavaScript остаётся понятнее для защиты.

**Проверка результата:** выполнена статическая проверка синтаксиса `js/Game.js` и целостности ZIP-архива. Перед сдачей следует вручную выполнить основной сценарий в браузере: начать игру; пройти влево и вправо; прыгнуть и выполнить двойной прыжок; собрать предмет; проверить столкновение с платформой, ямой и слизнем; потерять здоровье и подобрать сердечко; поставить игру на паузу; собрать все предметы и открыть выход; перейти к следующей главе; перезагрузить страницу и проверить сохранение.

**Собственные исправления после AI-помощи:** удалены вызов атаки и отрисовка снарядов, удалена подсказка об атаке, клавиши прыжка и паузы оставлены доступными с клавиатуры; README приведён в соответствие с фактическим управлением и механиками; ширина игровой оболочки уменьшена.

## Поддерживаемые браузеры и ограничения

Рекомендуются актуальные Chrome, Firefox, Edge и Яндекс Браузер с поддержкой Canvas 2D, ES6, `localStorage` и Web Audio API. При запрете локального хранилища сохранение может быть недоступно. При открытии через `file://` сохранения зависят от браузера и способа открытия файла; после публикации на GitHub Pages они привязаны к адресу сайта. Лестницы являются декором, отдельной механики лазания нет. Звуки синтезируются программно, а персонажи нарисованы пиксельными примитивами, а не отдельными анимационными листами.
